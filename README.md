A single fresh dad joke in classic question-and-answer form: Dad is late for dinner because his car is exhausted. `main.py` writes the joke to `entry.txt` as plain UTF-8 with no trailing newline.

[View the bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)

## Run

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
